# Modern Web Development Workflow

This skill guides the creation and enhancement of modern frontend web applications.

## Core Principles
1. **Modern Platform First**: Leverage HTML5 semantic elements (`<dialog>`, `<nav>`, `<main>`, `<article>`), Web Speech API for voice synthesis, and native audio.
2. **Component Architecture**: Keep components modular, accessible (`aria-*`, keyboard navigation), typed with TypeScript, and styled with utility classes.
3. **State Management**: Clean local state with React hooks, persisted state in `localStorage` or `IndexedDB`, and responsive design for all screen sizes (mobile, tablet, desktop).
4. **Delightful UX**: Smooth animations, sound feedback, micro-interactions, dark/light theme switching, and zero layout shifts (CLS = 0).
