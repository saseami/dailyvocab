# Antigravity Agent Configuration for EnglishLearner

This workspace contains the English vocabulary learning web application and the reference Astryx design system repository.

## Commands:
- `npm run dev`: Start Vite development server
- `npm run build`: Build production assets
- `npm run preview`: Preview production build
- `npx @astryxdesign/cli search <query>`: Search Astryx component specs and templates
- `npx @astryxdesign/cli template <id>`: View or scaffold Astryx templates

## Guidelines:
- Keep the user interface clean, aesthetic, fast, and accessible.
- Support both English and Vietnamese translations clearly.
- Preserve offline state and local progress in `localStorage`.
